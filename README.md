# upi-payment-qr-generator
A Python-based UPI Payment QR Code Generator that creates separate QR codes for Google Pay, PhonePe, and Paytm using the user's UPI ID. Built using Python and the qrcode library.

# UPI Payment QR Code Generator 

A simple Python project that generates UPI payment QR codes for multiple payment applications using a user's UPI ID.

##  Features

- Generate Google Pay QR Code.
- Generate PhonePe QR Code.
- Generate Paytm QR Code.
- Accept UPI ID from the user.
- Save generated QR codes as PNG images.
- Display QR codes automatically.

##  Technologies Used

- Python
- qrcode Library
- Pillow (PIL)

##  Installation

Install the required libraries:

pip install qrcode[pil]


##  How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install the required library.
4. Run the Python file:

python python.py

5. Enter your UPI ID.
6. The program generates QR codes for different payment applications.
